# BLAZIN IPTV Player

**BLAZIN IPTV Player** is a compact Windows IPTV player for user-provided legal sources.

Website: **https://windowsiptv.com**  
Download: **https://apps.microsoft.com/detail/9NQ5S0FFCN8T**  
Trial: **7-day free trial through the Microsoft Store**

## Supported Source Types

- M3U playlist URL
- Local M3U file
- M3U Plus
- Xtream Codes
- STB MAC
- Stalker Portal
- EPG guide data where supplied by the source
- Internal VLC-based playback and optional external player workflows

## Important Legal Note

BLAZIN IPTV Player is player-only software. It does **not** provide channels, playlists, subscriptions, streams, provider accounts, or copyrighted content. Users must provide their own legal IPTV source.
