# BLAZIN IPTV Player

**BLAZIN IPTV Player** is an all-in-one Windows IPTV player built for users who want speed, flexibility, a compact desktop experience, and a full TV-style interface in one app.

Whether you use **Xtream Codes**, **STB MAC**, **Stalker Portal**, **M3U files**, or **M3U playlist URLs**, BLAZIN IPTV Player brings your legal user-provided IPTV sources together in one Windows player.

## New in Version 1.1.7.0

BLAZIN IPTV Player now gives you **two ways to use the player**: the compact Windows desktop interface and the new **TV Mode** for a larger living-room-style experience.

### TV Mode Is Here

TV Mode is now included in BLAZIN IPTV Player. It provides a larger interface designed for TVs, big displays, mini PCs, and couch-style browsing while continuing to use the same profiles and supported source types as the desktop player.

TV Mode includes:

* Large-screen TV-style interface
* Live TV, Movies, and Series browsing
* EPG display for Live TV when supplied by the source
* Channel logos and Movie/Series artwork when available
* Categories, search, and favorites
* Keyboard and remote-style navigation
* Fullscreen playback
* Large-playlist browsing designed for TV use

### Redesigned Internal Player

Version 1.1.7.0 also introduces a redesigned compact internal player with an updated interface and improved playback experience.

New player improvements include:

* Redesigned compact internal player interface
* Background player loading to keep the main interface responsive
* GPU-assisted playback support through VLC where supported by the system
* Fullscreen channel-name marquee
* Fullscreen **Up/Down Arrow** channel switching
* Improved fullscreen controls
* Better control alignment when resizing the player
* New corner resize grips

### Profile Manager Improvements

The Profile Manager now also supports **playlist files**, making it easier to keep local M3U-based sources together with your other BLAZIN profiles.

## Best of Both Worlds

BLAZIN IPTV Player is designed to fit different Windows setups:

* Use the **compact desktop interface** when you want a smaller player that stays out of the way.
* Switch to **TV Mode** when you want a larger interface for a television, big monitor, mini PC, or couch-style setup.
* Use the built-in player or a compatible external media player depending on your setup.

## All-in-One IPTV Login Support

BLAZIN IPTV Player supports multiple IPTV source types from one app:

* Xtream Codes login
* STB MAC login
* Stalker Portal login
* M3U playlist file loading
* M3U playlist URL loading
* M3U Plus playlist support

When supported by the playlist or provider source, the app can organize content into:

* Live TV
* Movies
* TV Series

No need to switch applications just because your legal source uses a different supported format.

---

## BLAZIN-Fast Playlist Loading

BLAZIN IPTV Player uses **multi-threaded playlist processing** and background loading to help large IPTV playlists load while keeping the interface responsive.

Large IPTV lists can include thousands of Live TV channels, movies, and series entries. BLAZIN is designed to organize those lists into categories with search, favorites, EPG information, logos, and artwork when that metadata is supplied by the source.

## Built-In VLC Internal Player

BLAZIN IPTV Player includes a **built-in VLC internal player** for users who want playback directly inside the app.

Playback options include:

* Built-in VLC internal playback
* GPU-assisted VLC playback where supported
* External VLC player
* Other compatible external media players
* Fullscreen channel switching with Up/Down Arrow keys
* Fullscreen channel-name marquee

This gives users control over how they watch without being locked into one playback method.

## Why BLAZIN IPTV Player?

BLAZIN IPTV Player is built for users who already have their own legal IPTV source and want flexibility in how they browse and play it.

Instead of choosing between a compact desktop player and a large TV interface, BLAZIN provides both. You can work from a small Windows window during normal desktop use and switch to TV Mode when you want a larger viewing experience.

The app does not lock you into one login type, one playlist format, or one playback method.
