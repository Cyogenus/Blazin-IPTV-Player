BLAZIN IPTV Player User Guide

Learn how to install the Windows IPTV player, add M3U, M3U Plus, Xtream Codes, STB MAC, and Stalker Portal sources, use EPG, and choose playback options.

Quick setup

  1. Install from Microsoft Store.
    Download the official Windows app.
  2. Select a source type.
    Choose M3U, M3U Plus, Xtream Codes, STB MAC, or Stalker Portal.
  3. Enter source details.
    Use only legal playlists, accounts, or portals you are authorized to access.
  4. Load and browse.
    Use categories, search, favorites, Movies, Series, and EPG when available.
  5. Play streams.
    Use internal VLC-based playback or configure an external player.
