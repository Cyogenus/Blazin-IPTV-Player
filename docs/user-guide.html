Supported source types

BLAZIN IPTV Player supports M3U files, M3U playlist URLs, M3U Plus, Xtream Codes, STB MAC, and Stalker Portal sources when the source is compatible.

Users must provide their own legal IPTV playlist, account, or portal. BLAZIN IPTV Player does not provide channels or subscriptions.

Get started: Install BLAZIN IPTV Player from the Microsoft Store, open the app, choose the login type that matches your legal IPTV source, and follow the user guide for setup.
