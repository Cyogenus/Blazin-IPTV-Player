BLAZIN IPTV Player for Windows

BLAZIN IPTV Player is a fast, compact Windows IPTV player for users who want to load their own legal M3U, M3U Plus, Xtream Codes, STB MAC, or Stalker Portal source in one clean desktop app.

BLAZIN is designed for Windows users who want fast playlist loading, EPG support, internal VLC-based playback, external media player support, Movies and Series browsing when supported, themes, and a layout that does not take over the whole desktop.

Download from Microsoft Store View Screenshots

BLAZIN IPTV Player does not provide channels, playlists, accounts, subscriptions, or copyrighted content. Users must provide their own legal IPTV source.

Features

One Windows IPTV player for multiple source types

Instead of using separate players for different playlist formats, BLAZIN IPTV Player brings the most common IPTV login and playlist types into one Windows desktop app.

M3U & M3U Plus Player

Load M3U playlist files, M3U playlist URLs, and compatible M3U Plus sources.

Xtream Codes Player

Use server, username, and password login details for compatible Xtream Codes sources.

STB MAC & Stalker Portal

Support for compatible STB MAC and Stalker Portal sources with advanced options.

EPG Guide Support

View electronic program guide data when your IPTV source provides EPG information.

Internal VLC Playback

Play streams with the built-in VLC-based internal media player or use an external player.

Themes and Skins

Switch between visual themes and skins to match your Windows desktop style.

How to Use

How to use BLAZIN IPTV Player on Windows

  1. Install the app from the Microsoft Store.
    Download the official Windows version of BLAZIN IPTV Player.
  2. Choose your source type.
    Select M3U, M3U Plus, Xtream Codes, STB MAC, or Stalker Portal.
  3. Enter your playlist or login information.
    Add your URL, file, account, portal, or MAC details.
  4. Load your playlist.
    Browse Live TV, Movies, Series, categories, and EPG when supported.
  5. Start playback.
    Use the internal VLC-based player or configure an external player.

Best use cases

  • Windows IPTV player for M3U playlists.
  • Xtream Codes login support on Windows.
  • STB MAC and Stalker Portal support.
  • EPG guide support in a compact desktop player.
  • Theme options for different Windows desktop styles.
