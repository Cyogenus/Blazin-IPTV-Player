Features

One Windows app for multiple IPTV source types

Use one clean player for your own legal IPTV source instead of switching between different Windows IPTV apps.

M3U & M3U Plus

Load M3U playlist files, M3U playlist URLs, and M3U Plus sources in a compact Windows desktop layout.

Xtream Codes

Sign in with supported Xtream Codes credentials and browse Live TV, Movies, and Series when available.

STB MAC & Stalker

Use STB MAC and Stalker Portal login types for compatible portals with optional advanced settings.

EPG Support

View electronic program guide data when your IPTV source provides EPG information.

Internal VLC Playback

Play streams with the built-in VLC-based internal player or use an external media player.

Fast Playlist Loading

Designed with multi-threaded playlist loading for large IPTV playlists and smoother browsing.
