Troubleshooting

What to check if Xtream does not load as expected

  • Confirm the server URL, username, and password are typed exactly.
  • Check whether the source is active and reachable from your Windows device.
  • If Live TV loads but Movies or Series do not, the source may not expose those sections.
  • If guide data is missing, the source may not provide compatible EPG.
  • If artwork is missing, the source may not return logos or poster URLs.
