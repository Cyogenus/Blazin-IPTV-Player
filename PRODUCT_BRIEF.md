# BLAZIN IPTV Player Product Brief

## Product name
BLAZIN IPTV Player

## Website
https://windowsiptv.com

## Microsoft Store
https://apps.microsoft.com/detail/9NQ5S0FFCN8T?cid=Blazin_website

## Platform
BLAZIN IPTV Player is a Windows IPTV player for Windows 11 and Windows 10.

## Important legal/compliance wording
BLAZIN IPTV Player does not provide IPTV channels, playlists, subscriptions, provider accounts, copyrighted content, or streaming services.

Users must provide their own legal IPTV source, such as:
- M3U playlist
- M3U URL
- M3U Plus URL
- Xtream Codes login
- STB MAC portal
- Stalker Portal login

Do not link to IPTV providers or illegal streaming services.

## Main positioning
BLAZIN IPTV Player is a native Windows IPTV player built for users who want to manage their own IPTV sources on a PC, laptop, Surface, or Windows desktop without relying on Android emulators.

## Core features
- Windows IPTV player for PC, laptop, and desktop
- Supports Live TV, Movies, and Series sections
- Supports M3U playlists
- Supports M3U URL playlists
- Supports M3U Plus
- Supports Xtream Codes login
- Supports STB MAC login
- Supports Stalker Portal login
- Supports EPG / TV guide when provided by the user’s playlist or provider
- Supports channel logos when available
- Supports movie posters and series posters when available
- Supports categories for Live TV, Movies, and Series
- Supports search
- Supports favorites
- Supports playlist/category organization
- Supports internal player
- Supports external media players
- Supports VLC
- Supports MPC-HC / MPC-BE style external playback
- Supports custom user agent settings
- Supports advanced Stalker/STB fields for compatibility
- Designed for large playlists
- Designed for smaller laptop screens
- Includes themes/skins
- Default theme is Blue Grey
- Includes 7-day free trial through Microsoft Store

## Player support
BLAZIN IPTV Player can use an internal player and can also launch external players depending on user settings.

External playback may be useful for users who prefer VLC, MPC-HC, MPC-BE, or advanced video renderers such as MadVR.

## IPTV source support

### M3U
Users can load M3U playlist files or M3U playlist URLs. M3U support is useful for users who already have a legal playlist source.

### M3U Plus
Users can load M3U Plus style URLs when provided by their IPTV source.

### Xtream Codes
Users can sign in using Xtream Codes details when their legal IPTV source supports Xtream Codes API access.

### STB MAC
Users can use STB MAC style portal login when supported by their legal IPTV source.

### Stalker Portal
Users can use Stalker Portal login when supported by their legal IPTV source.

## EPG
BLAZIN IPTV Player supports EPG / TV guide data when the user’s legal IPTV source provides valid EPG data.

Do not claim that every playlist will have EPG. Some sources may not provide guide data.

## Posters and logos
BLAZIN IPTV Player can show channel logos, movie posters, and series posters when the user’s IPTV source provides them.

Do not claim every source will include posters or logos.

## Important wording for “free”
The app has a 7-day free trial.

Do not call the app permanently free unless the Microsoft Store listing is changed to free.

Correct wording:
“Try BLAZIN IPTV Player with a 7-day free trial.”

Incorrect wording:
“Free IPTV channels”
“Free IPTV subscriptions”
“Free IPTV service”
